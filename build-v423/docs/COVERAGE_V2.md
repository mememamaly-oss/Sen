# SENTINEL v4.1.0 — التغطية متعددة الأبعاد (Coverage 2.0)

> المرجع التنفيذي لطبقة الأبعاد في `coverage.py` — من نسبة واحدة إلى 17 بُعدًا قابلًا للتدقيق.

## الأبعاد الـ17

| البُعد | ما يقيسه | مصدر التغذية |
|---|---|---|
| endpoint | النقاط المكتشفة/المختبرة (الحساب الكلاسيكي) | الزحف/OpenAPI/المتصفح |
| parameter | المعاملات التي لمسها مسبار فعلي | _CoverageProxy (آلي) |
| authentication | أنماط المصادقة الممارسة (form/token/مجهول/إعادة مصادقة) | محرك المصادقة |
| identity | الهويات المُسجَّلة دخولها فعلًا والمستخدمة | authz + الجلسات |
| authorization | خلايا مصفوفة الدور×السطح المُستقصاة | محرك authz |
| entity | الكيانات التي نال أحد أسطحها اختبارًا | التوأم |
| object | معرفات الكائنات المستخدمة في هجمات/أدلة | التوأم + سجل الهجمات |
| workflow | التدفقات المُتعلَّمة/المُهاجَمة | محرك سير العمل |
| workflow_branch | الفروع: مُمارَسة (functional/هجوم) أم مُعلَنة فقط | الرسم البياني |
| state | انتقالات الحالة المُلاحظة/المُختبرة | أزواج حالة الخطوات |
| api_protocol | http/openapi/graphql/websocket | الجرد الموحد |
| graphql | نقاط GraphQL المكتشفة/المختبرة | محرك GraphQL |
| websocket | القنوات المكتشفة/المختبرة | محرك WebSocket |
| browser | صفحات العرض/فحص DOM | محرك المتصفح |
| oast | القناة المسلَّحة والتفاعلات | OAST |
| detector | الكواشف التي أرسلت مجسات فعلًا | عدّادات المنسّق |
| evidence | النتائج المثبتة مقابل ملفات الإثبات | Evidence OS |

## القواعد المفروضة

1. **بيان الغياب**: بُعد بصفر مكتشف = `NOT_DISCOVERED` مع ملاحظة "no X surface
   was observed" — **أبدًا** لا يُقال "GraphQL مختبر" دون اكتشاف (بوابة عدم الهلوسة G4).
2. **حارس الـ100%**: النسبة تُحسب عبر `boundary.honest_pct` — وجود سجل حدودي
   غير محلول في فئة البُعد يمنع الادعاء الكامل (99.9 + ظهور السبب) (G5).
3. **حساب قابل للتدقيق**: كل بُعد يحمل `discovered/tested/untested/untested_reasons`
   + عينة عناصر (مفتاح/وصف/هل اختُبر/سبب عدم الاختبار).

## الوصول

- `cli.py report --format json` → `stats.coverage.dimensions`
- التقرير التقني HTML → قسم "Coverage 2.0 — التغطية متعددة الأبعاد"
- التقرير التنفيذي → `capability_matrix` (مشتق من الأبعاد نفسها)
- `cli.py capability-matrix --db ...` → ملف Markdown مولَّد آليًا
- SARIF → `runs[0].properties.coverage.dimensions`
- بوابة عدم الهلوسة → 3 قواعد (G3/G4/G5) على الأبعاد مباشرة
