# SENTINEL — معمارية واجهة المنتج (Phase 01)

> **النطاق:** تحويل طبقة العرض فقط. المحرك (`build-v411/sentinel`) وقنوات الـ API لم تُمسّ —
> `git diff v4.1.1 -- build-v411 gap-validation` = فارغ (0 بايت)، وكل بوابات المحرك أُعيد
> تشغيلها بعد أعمال الواجهة: 102/102 + doctor 15/15 + benchmark ×3 (F1=1.000).

## 1. مبادئ التصميم (Design Doctrine)

1. **وحدة لغة الخطورة**: مقياس واحد في كل مكان — critical/high/medium/low/info —
   نفس الألوان في الشرائح والرسوم والجداول والتفاصيل. لا استثناءات.
2. **Console هادئ لا لوحة ألوان صاخبة**: أسطح عميقة هادئة، حدود دقيقة، لون تمييز واحد
   (سيان SENTINEL). المنتج غرفة عمليات أمن، ليس لعبة.
3. **صدق قبل التضخيم**: كل رقم على الشاشة من واجهات المنصة، وكل واجهة من المحرك.
   لا حالة فارغة تُخفى، ولا حد يُدّعى، ولا "قريب من" — إما مُوثّق أو غير موجود.
4. **ميزانية الحركة ≤ 180ms**: انتقالات قصيرة فقط، احترام كامل لـ
   `prefers-reduced-motion`، لا parallax ولا ارتدادات.
5. **RTL أولًا**: خصائص منطقية فقط (`ms-/me-/ps-/pe-`، `start/end`)؛ الأرقام والمعرّفات
   والشيفرات دائمًا LTR داخل نص RTL (`.num { direction: ltr; unicode-bidi: isolate }`).

## 2. الكومة التقنية (بلا اعتماديات جديدة)

استُخدمت **الاعتماديات الموجودة حصرًا** في `package.json` (لم يتغير `bun.lock`):
Next.js 16 (App Router) + TypeScript + Tailwind 4 + shadcn/ui (Radix) + **recharts**
(رسوم النظرة العامة) + **lucide-react** (أيقونات). لا مكتبات i18n خارجية، ولا محرك
سمات خارجي، ولا مكتبات خطوط خارجية.

## 3. بنية المسارات (14 مسارًا حقيقيًا قابلًا للربط العميق)

```

/                              توجيه ذكي: موثّق → /overview، وإلا → /login
(app)/overview                 لوحة تنفيذية (KPIs + توزيع الخطورة + مقياس التغطية + أحدث الفحوصات)
(app)/targets                  سجل أسطح الهجوم (بحث/فرز/إضافة: مُدار أو مخصص)
(app)/scans                    سجل التشغيلات (تصفية بالحالة + ?target=)
(app)/scans/[id]               مراقبة الفحص: مباشر (2.5s) ثم النتائج والتغطية والحدود والتقارير
(app)/findings                 مستكشف الثغرات (اختيار فحص + بحث/تصفية خطورة/فرز)
(app)/findings/[id]            تفاصيل الثغرة (الدليل/التحقق/الأثر/الإعادة/المعالجة)

(app)/reports/[id]             عارض التقارير (HTML/GLASS داخل iframe معزول؛ SARIF/JSON خام)
(app)/twin                     التوأم الرقمي — إحصاءات المحرك الحالية + إعلان صريح للمرحلة 02
```

كل مسار قابل للمشاركة والإشارة المرجعية والرجوع/التقدّم في المتصفح — بعد أن كانت P0
صفحة واحدة بحالة عرض داخلية.

## 5. نظام السمات (Tokens)

- **داكن (افتراضي — "سطح القيادة 02:00")**: خلفية `oklch(0.165 0.02 262)`، أسطح
  `0.205`، تمييز سيان `oklch(0.78 0.13 195)`، ظلال ناعمة عميقة.
- **فاتح ("غرفة العمليات صباحًا")**: خلفية `0.977`، أسطح بيضاء، نفس التمييز بدرجة أعمق
  للتباين `0.55`.
- **الخطورة**: critical `oklch(0.66 0.22 16)` / high `0.73 0.16 55` / medium `0.83 0.16 90`
  / low `0.72 0.12 230` / info `0.68 0.02 255` — نفس القيم في الوضعين مع تعديل فاتح/داكن.
- **الطباعة**: Cairo مُستضاف محليًا (subsets عربي+لاتيني 400/700/900، `public/fonts/`) —
  عائلة واحدة للغتين. الأرقام والمعرّفات بخط أحادي المسافة مع `tabular-nums`.
- **التبديل**: `localStorage` + `.dark` على `<html>` + `color-scheme` — بلا وميض
  (القيمة الافتراضية داكن في الخادم).

## 6. i18n و RTL/LTR

- قاموس مكتوب نوعيًا (`DictKey`) في `src/lib/ui/i18n.tsx` (~240 مفتاحًا × لغتين) —
  `t(key)` في كل نصوص الواجهة. محتوى المستخدم (أسماء الأهداف، أنواع ثغرات المحرك،
  إجراءات التدقيق) يُعرض كما هو — لا ترجمة اختراعية.
- `dir` يتبع اللغة (`rtl`/`ltr`) ويُطبَّق على `<html>`؛ كل الأنماط بخصائص منطقية.
- التواريخ والأرقام عبر `Intl` بمقعد `ar-LY` / `en-GB`، والمدد النسبية عبر
  `Intl.RelativeTimeFormat`.

## 7. نظام الحالات (كل سطح غير متزامن)

- **تحميل**: هياكل عظمية لامعة (shimmer) — بطاقات/جداول — لا سبينرات مزدحمة.
- **خطأ**: بطاقة `role="alert"` + زر إعادة محاولة يعيد الطلب نفسه.
- **فراغ**: عنوان + تلميح + إجراء (مثال: "لا ثغرات — إمّا لم يكتمل الفحص أو لم يرصد
  شيئًا؛ الصدق قبل التضخيم").
- **نجاح**: Toast (أربع صور، إخفاء تلقائي 4.6s مع إيقاف عند التحويم، `aria-live=polite`).
- حالة "قيد التشغيل" الحية: نقطة نبض + شريط تقدم + سجل المحرك بأسلوب طرفية، مع
  تحديث محلي كل ثانية بين استطلاعات كل 2.5 ثانية.

## 8. الوصولية (A11y)

- رابط "تخطَّ إلى المحتوى"؛ حلقات تركيز مرئية (`:focus-visible`) بكل المكوّنات.
- `aria-current="page"` في التنقل؛ `aria-pressed` في مرشّحات الشرائح؛
  `role="meter"` في أشرطة التغطية/الثقة؛ `aria-live` في الإشعارات وحالات الانتظار.
- لوحة المفاتيح: التنقل والقوائم والحواريات كلها عبر shadcn/Radix (دعم مفتاحي مكتمل).
- `prefers-reduced-motion`: كل الحركات → 0.01ms (قاعدة عامة في globals.css).

## 9. تدفق البيانات (Renderer-Pure)

```
المحرك (build-v411) — يُنادى كصندوق أسود عبر src/lib/engine.ts (لم يتغير)
   ↓ مسارات API (13 مسار P0 — لم يتغير عقد واحد؛ أُثبت بـ E2E 68/68 على البناء الجديد)
src/components/saas/api.ts (عقد مكتوبة نوعيًا — نفس P0)
   ↓ useAsync/usePolling (حالة موحدة + إعادة محاولة + استطلاع حي)
صفحات (app)/* — عرض فقط: لا تُولّد الواجهة أي ادعاء أمني ولا تخفي حدًا
```

التوأم الرقمي في هذه المرحلة يعرض **ما يخرجه المحرك اليوم فقط** (أبعاد التغطية 17،
جرد النقاط، فئات الحدود) ويعلن صراحة أن الرسم التفاعلي الكامل هو المرحلة 02 من
خارطة الطريق المعتمدة — بلا أي بيانات رسم مُختلقة.
