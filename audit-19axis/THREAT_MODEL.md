# THREAT MODEL — SEN (Axis 1, 2026-10-23)

المنهجية: STRIDE مُبسَّط + ترتيب حسب (الشدة × قابلية الاستغلال) مع توضيح الافتراضات. كل أصل/مدخل مستنتج من خريطة النظام الموثقة (SYSTEM_MAP.md).

| ID | المهاجم | القدرات | الدافع |
|---|---|---|---|
| T1 | مستخدم مسجل منخفض الصلاحية (MEMBER/VIEWER) | حساب صالح، طلبات API مصادقة | تسلّل أفقي (IDOR)، تصعيد صلاحيات |

## 3. نقاط الدخول وحدود الثقة

1. **:81 (Caddy الحي)** — إنترنت → حاضنة: *حد الثقة الأول والأضعف حالياً* (ENV-1: اختيار upstream من query — مثبت حياً).
2. **:3000 (Next.js)** — طلبات مصادقة/غير مصادقة؛ 19 مسار API خلف سلسلة requireUser/requireOrgAccess.
3. **تسجيل الدخول (NextAuth credentials)** — هدف T3: تخمين (يُحد بـ 10/15د لكل بريد و50/15د لكل IP)، تعداد حسابات (مُعادلة التوقيت بـ dummy scrypt).
4. **إنشاء الأهداف** — URL من المستخدم: بوابة SSRF المحتملة (تُرفض الشبكات الخاصة إلا بوضع مختبر صريح + إعادة فحص النطاق في المحرك بعد التوجيهات).
5. **المحرك → الهدف** — خارج الثقة: ردود الهدف تعالج كبيانات عدائية (ترميز/تعقيم في التقارير + sandbox في العارض + بذور عشوائية للتوقيع).
6. **spawn المحرك** — app → python: argv فقط، لا shell، مسار ثابت من resolveProjectRoot.

## 5. الافتراضات

1. الحاضنة جدران نارية على مستوى المنصة؛ المنفذ 81 قابل للتوجيه للإنترنت (مؤكد: الوصول عبر الواجهة العامة نجح).
2. المهاجم لا يملك صلاحيات root داخل الحاضنة (وأنا أيضاً لا أملكها — وهذا سبب بقاء ENV-1).
3. أهداف الفحص الخارجية غير موثوقة (T4) — حتى لو كانت مواقع اختبار معتمدة.
4. المستودع البعيد (GitHub) موثوق كنسخة، وهو الآن **خاص**؛ الدفع يتطلب PAT (متحقق).
5. نشر واحد (عملية standalone واحدة) — نموذج الذاكرة للـ rate limiter صالح لهذا النشر فقط (موثق في `src/lib/rate-limit.ts`).

## 6. المخاطر المقبولة المتبقية (Residual — بلا معالجة في هذه المهمة)

- ENV-1 (S1): خارج نطاق صلاحياتي — يتطلب مشغّلاً مخوّلاً (قاعدة البوابة تحكم عليه بالأحمر).
- CSP يحمل `unsafe-inline`/`unsafe-eval` (متطلب hydration لـ Next): يضعف حاجز S5 الثانوي؛ مقبول لأن الخط الأول (sandbox='') مثبت.
- لا TLS في نشر الحاضنة (HTTP داخلي): كوكيز `secure` غير مفعلة — قيد نشر موثق.
- لا مراقبة/تنبيهات إنتاجية فعلية (سجلات تدقيق فقط) — موثق كفجوة (المحور 15).
- اختبار خارجي/staging غير متاح — فجوة إلزامية (تبقي البوابة RED).
