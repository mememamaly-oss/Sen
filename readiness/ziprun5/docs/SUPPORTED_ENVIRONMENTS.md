# البيئات المدعومة — SENTINEL v4.0.0

## مضمّنة (مختبرة فعليًا في حملة الجاهزية)

| المكوّن | الإصدار المختبر | ملاحظات |
|---|---|---|
| Python | 3.12.14 و 3.13.5 | نفس الأعمال خضراء على الاثنين (نقاء stdlib كامل) |
| Linux x64 | glibc (Debian-based) | بيئة التطوير والاختبار والجاهزية |
| SQLite | 3.53 (عبر stdlib) | WAL مفعّل |
| OpenSSL | 3.5.x | طبقة TLS ل HTTPS |
| Playwright + Chromium | حديث | اختياري — محرك DOM الكامل |
| Node.js (كهدف) | 20/22/24 — Juice Shop 20.2.0 | فُحص كهدف حي (SPA/REST/JWT) |
| Java (كهدف) | Spring Boot — WebGoat 8.2.2 / WebWolf 8.2.2 | فُحصت كأهداف حية |
| HTTPS بأهداف خارجية | ginandjuice.shop | فحص مُصادق + OAST عام |

## متوقعة العمل دون ضمان رسمي
- macOS (Python 3.10+): لا استخدام لمكتبات نظام خاصة؛ يتوقع التطابق.
- Windows: غير مختبر في v4.0.0 — الواجهة CLI قياسية لكن مسارات/أذونات 0600
  تتصرف بصورة مختلفة (مفتاح الخزنة). (خارطة طريق للاختبار.)

## أهداف الفحص المدعومة
- HTTP/HTTPS، نماذج HTML، JSON REST APIs، توكنات Bearer/JWT/raw-header،
  مواصفات OpenAPI/Swagger، JS ثابت + XHR/fetch في المتصفح، robots/sitemap،
  OAST محلي/عام، مصادقة نماذج متعددة الحسابات، سير عمل متعدد الخطوات.

## قيود بيئية معروفة
- جدار حجب الخروج → تعطل فحوص الأهداف الخارجية وقناة OAST العامة (يعمل doctor
  على إظهارها مبكرًا).
- أقراص الشبكة المشتركة → لا تستخدمها لقاعدة `--db` مع عمليات متزامنة (قفل WAL).
- بيئات التشغيل الآلي بسقف زمني للنداء → قسّم الفحوصات الكاملة (الزحف المهذب
  التسلسلي بطيء بحسب زمن استجابة الهدف).
