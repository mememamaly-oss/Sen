## 2. الأفعال المسموحة — كشف فقط
مسبارات المحرك التفاضلية القياسية؛ ممنوع: الاستغلال، تخمين اعتمادات، كتابة/تعديل بيانات،
ثبات، رفع بيانات. OAST معطّل، متصفح DOM معطّل (قد يجلب موارد خارج القائمة).

## 3. سقف المعدل والميزانية
- ≤ 2 طلب/ثانية إجبارياً (وكيل rate_proxy.py v1.1 بدلو رموز — سجل JSONL هو الدليل)
- لكل هدف: ≤ 600 طلب و ≤ 15 دقيقة زمن جداري
- إيقاف فوري عند: 3 أخطاء 5xx متتالية، أو 429، أو كمون متزايد >5× الأساس

## 4. المعايير المسجلة سلفاً
- كل مسح عبر الوكيل الخانق v1.1 (تمرير حرفي لترويسات المصدر — إصلاح F2 المُلزم)
- بذرة 20261020، max-pages 8، timeout 12s، النتائج الخام كما تأتي (قد تكون صفراً وتُسجَّل)
- سجل الوكيل + تقرير المسح + SHA256SUMS = الإيداع
